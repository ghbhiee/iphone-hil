# 提示词：让 Claude 从零做「iPhone 屏幕后台截帧 → 读报告」

> 新开一个 Claude Code 会话，整段贴进去。手机先接线、解锁、自动锁定设为永不。
> 如果这台 Mac 上已经克隆了本项目，直接按 README 用 `hil` 命令即可；这段提示词是给**没有**本项目的机器准备的：只描述需求，让 Claude 自己从零做出来。

---

我的 iPhone 用数据线接在这台 Mac 上，已解锁并信任了电脑。请你通过 USB 读到 iPhone 的屏幕画面（QuickTime 录 iPhone 屏幕用的那条通道），做一个后台程序：画面变化并停稳就自动存一帧。我自己在手机上逐份打开体检报告，不需要你操作手机。我说"翻完了"之后，你把存下来的帧读一遍，整理成一张表，异常项单独列。先把程序跑起来、截一帧给我确认清晰，再开始。

---

可选的一句提醒（能省掉最大的坑）：相机权限按 App 授予，Claude Code 自己拿不到，采集程序要做成独立的 .app 启动。
